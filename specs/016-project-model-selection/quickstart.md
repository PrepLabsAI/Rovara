# Quickstart: Project Worker Model Selection

Register a project revision whose `models.default` appears in `models.approved`. Use unique labels and verify each model is enabled in the deployment account and region.

```text
@agentx models
@agentx use fast
```

Selection applies to every project workspace on its next turn. Confirm the next coding task's usage reports the selected pair. Deploy worker support before broker payloads, then deploy Slack; projects without `models` keep using environment defaults.
